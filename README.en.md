# Python — Object-Oriented Programming

Repository with exercises and practical systems built in Python, applying the four pillars of Object-Oriented Programming: **abstraction**, **encapsulation**, **inheritance**, and **polymorphism**.

---

## 🧠 Pillars Practiced

| Pillar | What it is | Where it was applied |
|---|---|---|
| **Encapsulation** | Protecting a class's internal data | `encapsulamento.py`, `sistemaBancario.py` |
| **Inheritance** | Reusing behavior across classes | `formaGeometrica.py`, `sistemaVeiculos.py` |
| **Polymorphism** | Same method, different behaviors | `polimorfismo.py`, `zoológico.py` |
| **Abstraction** | Modeling real-world entities as classes | All systems |

---

## 📁 Projects and Exercises

### 🏦 Banking System — `sistemaBancario.py`
Simulation of bank accounts with deposit, withdrawal, and balance operations. Uses encapsulation to protect account data.

### 👨‍💼 Employee System — `sistemaFuncionario.py`
Modeling of employees with different roles and salaries. Uses inheritance to specialize employee types.

### 💳 Payment System — `sistemaPagamento.py`
Different payment methods (card, bank slip, etc.) with polymorphism to process each type.

### 🚗 Vehicle System — `sistemaVeiculos.py`
Vehicle hierarchy using inheritance — a base vehicle specialized into specific types.

### 🚌 Transport System — `sistemaTransport.py`
Modeling of means of transport applying inheritance and polymorphism.

### 📦 Product — `produto.py`
Product class with encapsulation of price and quantity.

### 🔺 Geometric Shapes — `formaGeometrica.py`
Inheritance between shapes (circle, rectangle, triangle) with area and perimeter calculation via polymorphism.

### 🦁 Zoo — `zoológico.py`
Animals with polymorphic behaviors — each animal makes sounds and acts differently while sharing the same interface.

### 🔒 Encapsulation — `encapsulamento.py`
Direct exercise on public, private, and protected attributes with getters and setters.

### 🔁 Polymorphism — `polimorfismo.py`
Practical exercise demonstrating method overriding and common interfaces across different classes.
